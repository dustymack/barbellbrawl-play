App icon options

The current icon is a thin, hairless stick figure. The fighter has since grown a V-shaped torso, muscle that bulks up with STR, spiky hair, an orange headband and a soft glow. These options are drawn with the same fighter code as the buddy on the week card, so they match it exactly. Everything important stays inside Android's adaptive-icon safe circle, so one PNG can serve as both icon.png and the adaptive foreground.
